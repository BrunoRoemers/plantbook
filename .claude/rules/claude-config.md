# Claude configuration

Claude settings for this project live in the repo's `.claude/`, never at user level (`~/.claude`, including auto-memory):

- instructions and conventions → `.claude/CLAUDE.md` or `.claude/rules/*.md`
- workflows → `.claude/skills/`
- permissions, hooks, env → `.claude/settings.json`

When asked to remember something, write it here so it's versioned and reviewed like any other change.
