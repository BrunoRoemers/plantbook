# Writing docs

- Short beats complete. Leave out open questions and details that don't block the next step; we settle them by trying things.
- Numbering: `NNN`, zero-padded, next free number, never reused.
- Specs: use the `spec` skill's template. Status: `draft` → `ready` (set by Bruno) → `done`.
- Decisions: `Status: proposed | accepted | superseded by NNN`, with a date. A sentence of context, then the decision. Supersede an accepted decision with a new one rather than rewriting it.
- Domain model: update it in the same change as code that changes the model or vocabulary.
